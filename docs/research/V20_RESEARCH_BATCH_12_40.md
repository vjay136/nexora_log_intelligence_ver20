## Integration guidance for NLI

Reuse patterns at the boundary, not upstream implementations: bounded reads and explicit size errors (Prometheus), deterministic queue/ack separation (Logstash/Beats), declarative component graph ideas (Alloy), explicit limits/health metrics (Tempo), admission control/backpressure (Quickwit), staged and locked promotion (Elastic Agent), and canonical field semantics (ECS). Keep parser outcomes separate from transport success; preserve unknown/malformed records and report partial/abstain rather than silently dropping them (NuLog illustrates the risk). No arbitrary generated source or upstream parser/plugin code is recommended from this review.

This batch did not run upstream tests, audit transitive dependencies, or validate license compatibility for a product distribution. For implementation-ready reuse, inspect exact dependency trees, per-file headers, bundled/generated artifacts, and repository notices first.
