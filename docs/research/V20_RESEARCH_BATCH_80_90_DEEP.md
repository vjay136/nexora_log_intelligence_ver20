## Cross-project observations

The counted files describe infrastructure rather than a universal log parser. Protobuf’s compiler parser demonstrates a mature schema grammar and precise diagnostics; spdlog demonstrates carrying timestamp, source, level, and message as event fields before sink-specific rendering. NLI can adopt those separations and use deterministic malformed-input tests, while keeping raw-record preservation, schema evolution, and parser confidence semantics owned by NLI. No performance figures were reproduced, and dependency graphs were not audited.
