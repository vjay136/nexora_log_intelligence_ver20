### #38 `elastic/kibana`

- Evidence: focused log tokenizer implementation [`extract_grok_pattern.ts`](https://github.com/elastic/kibana/blob/main/x-pack/platform/packages/shared/kbn-grok-heuristics/src/tokenization/extract_grok_pattern.ts), its unit test [`extract_grok_pattern.test.ts`](https://github.com/elastic/kibana/blob/main/x-pack/platform/packages/shared/kbn-grok-heuristics/src/tokenization/extract_grok_pattern.test.ts), [repo license notice](https://github.com/elastic/kibana/blob/main/LICENSE.txt), and [active main history](https://github.com/elastic/kibana/commits/main/). GitHub issue [#234044](https://github.com/elastic/kibana/issues/234044) identifies that exact test and reports a slow-tokenization failure on Proxifier LogHub samples, with the test path and timeout. This is strong evidence that the code/test pair addresses grok pattern extraction from real log samples and has an explicit performance concern. NLI transfer: useful tokenizer/token-boundary extraction and regression fixture design; it is heuristic Grok pattern induction, not general event-template mining. Root license is conditional: default triple AGPL-3.0-only/SSPL-1/Elastic-2.0, while x-pack-only code is Elastic License 2.0; verify applicable file header before reuse. Large monorepo/dependency surface. Confidence: high for relevance and issue-backed performance caveat.
